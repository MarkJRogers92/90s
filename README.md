# 90s — M2 Interaction Lab

This repository contains the M0–M2 playable prototype for the 90s game, including the preserved M1 Janitor combat room and the deterministic M2 Interaction Lab.

## Run locally

```text
npm install
npm run dev
```

Open `http://127.0.0.1:5173`, then choose **Start shift** for M1 or **Interaction Lab** for M2. In the lab, try the curated builds, owned-item toggles, primary selection, WASD/pointer aim, primary click, and Escape.
