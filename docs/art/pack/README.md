# DEAD MALL — Visual Bible Reference Set

Art-only archive based on `codex/m4-void-the-warranty`. This branch changes no gameplay code.

This set contains the approved initial visual-reference boards plus the continuation boards generated in the art-only session. Generated boards are reference material for Aseprite production rather than finished runtime sprite sheets. When a generated board conflicts with the canonical source brief, the source brief wins.

Core direction: 640×360 internal viewport; 3/4 top-down; detailed late-SNES/Aseprite-first pixel art; four-direction body movement with eight-direction aimed arms/equipment; shared material ramps, store accent palettes and corruption palettes; modular store kits with bespoke identity pieces; two-tier item art; large detailed portraits.

The repository copies are browse/reference copies. Source PNG/JPG hashes and the lossless local archive are tracked separately so source provenance is not lost.
