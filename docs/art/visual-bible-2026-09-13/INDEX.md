# DEAD MALL Visual Bible Index

This art-only branch is based on the current M4 gameplay branch. It is the repository home for the approved visual direction and subsequent art-reference production. No gameplay code is changed here.

The catalog tracks 10 initial approved reference boards, 8 art-only continuation boards, and 9 supporting crop/reference images. The canonical requirements remain the user-supplied production brief: detailed late-SNES/Aseprite-first art, 3/4 top-down presentation, 640×360 internal target, modular store kits, two-tier item art, eight-direction aiming overlays, substantial portraits, and retail-preserving horror corruption.
