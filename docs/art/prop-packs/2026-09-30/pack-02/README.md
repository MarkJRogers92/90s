DEAD MALL prop pack 02
=====================

Four static props: arcade cabinet, soda vending machine, mall planter, janitor cart.

The root PNG files are the main native-size sprites. small/ contains independently converted compact variants. All eight exports have binary transparency and use only the shared 32-color DEAD MALL profile palette. Use nearest-neighbor filtering and preserve aspect ratio.

aseprite/ contains single-layer editable masters of the main sprites, each tested pixel-for-pixel through an export roundtrip. Matching Pixel Forge JSON is included for both sizes. previews/ contains enlarged reference images, not runtime sprites.

Sources, prompts, QA reports, provenance and verification are included. These are standalone artwork candidates and have not been integrated or play-tested in the game. See manifest.json for dimensions, exact color counts and visual limitations.
