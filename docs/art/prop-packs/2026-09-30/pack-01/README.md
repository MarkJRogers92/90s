DEAD MALL prop pack 01
=====================

Four static props: gumball machine, mall directory, wet-floor sign, CRT TV cart.

Use the root PNG files at their native sizes with nearest-neighbor filtering. Smaller independently converted variants are in small/. All eight exports have binary transparency and use only the shared 32-color DEAD MALL profile palette.

The aseprite/ folder contains single-layer editable main sprites; each was roundtrip-tested pixel-for-pixel. Matching Pixel Forge JSON files support direct pixel edits. previews/ contains enlarged reference images, not runtime sprites.

Prompts, high-resolution sources, conversion reports, and provenance are included for future revision. The gumball exports retain a few isolated colored detail pixels flagged by automated QA; review them at your intended in-game scale.

These are standalone artwork candidates. They have not been wired into the game or play-tested.
